# PF1e dataset candidates

> **Retired import.** This document describes the upstream import that built the library before it moved to the pinned plain-text corpus. The import code is preserved at the git tag `psrd-last-buildable`; the facts below stay as evidence and history, and the paths they name no longer exist on `main`.

Research checked 2026-11-03. This compares public GitHub repositories and their published source material for a free, offline PF1 reference. It does not establish legal clearance. A repository license for code does not license game text stored beside that code; a crawler's existence does not grant permission to redistribute its output.

This candidate was missing from the earlier comparison.

## AoN and d20PFSRD repository checks

- AoN: the [archive root README](https://github.com/SirRodericMurgatroyd/aonprd-archive/blob/main/README.md) calls the 1e crawl complete and lists a 200 MB release tarball. The [1e README](https://github.com/SirRodericMurgatroyd/aonprd-archive/blob/main/1e/README.md) describes a breadth-first crawl, says list pages enumerate IDs, and clearly limits the claim to link-reachable content. Its archive contains raw HTML, not a structured export. No license file or GitHub license metadata was present when checked. The scripts' permission to crawl does not establish permission to redistribute source-site content.
- d20PFSRD: its [legal page](https://www.d20pfsrd.com/extras/legal/) includes OGL 1.0a, identifies d20PFSRD artwork and site branding as Product Identity, and says site illustrations cannot be reused without express permission. The page also states its site may contain affiliate links and third-party material. This makes it a poor source for an unattended bulk import: legal labels and copyright holders must be resolved per contribution.
- Paizo: the current [Community Use Policy](https://paizo.com/licenses/communityuse), last updated 2024-08-22, applies to free websites and software, prohibits charging for access, requires an unofficial-status notice and visible current contact information, and allows descriptive reference to names and locations. Paizo's [licenses overview](https://paizo.com/licenses) says OGL mechanics require the applicable OGL route and describes Community Use as non-commercial. Neither page is a promise that every passage found on AoN or d20PFSRD can be republished, and neither clears third-party rights. The existing [licensing audit](licensing-audit.md) records Cast Iron's current scope and notice review.

## Recommendation for Cast Iron

Keep PSRD-Data as the implementation baseline while treating source selection as a publication and rights boundary. Its typed JSON and ordered rules trees already map to the Rust compiler's deterministic typed-node pipeline. Use the AoN archive as a research/reference corpus to identify coverage gaps, then add only explicitly reviewed and source-pinned material through a native Rust adapter. Preserve URL-derived permanent `EntryId`s where possible, and report omitted or unsupported records in coverage. Keep relationship extraction explicit and validated; do not assume a crawl or site taxonomy supplies complete prerequisites, spell lists, or cross-links.

Before considering any new corpus for public distribution, check the exact repository snapshot, source-book notices, page-level OGC/PI declarations, third-party contributions, and Paizo policy requirements. Exclude artwork and Product Identity; do not bundle raw HTML or add runtime scraping. The evidence found does not support replacing the current dataset with a complete, cleanly licensed AoN or d20PFSRD structured database.
