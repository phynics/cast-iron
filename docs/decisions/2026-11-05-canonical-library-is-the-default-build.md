# Canonical library is the default build, 2026-11-05

- **The canonical library owns `generated/content/`.** `cargo xtask content` compiles the screened Pf Data corpus, applies the legal screen and carry-over, and writes `generated/content/`; `cargo xtask build-site` packages that directory by default. `generated/content/` is the conventional location many scripts and the verify skill already read, so the default moved into it instead of adding a third path.
- **PSRD-Data moves behind `--psrd`.** `cargo xtask content --psrd` writes `generated/psrd/` with reports under `generated/reports/psrd/`; `cargo xtask build-site --psrd` packages it. It remains the carry-over input and the last published library, so it stays buildable for inspection, the upgrade check, and the deterministic-content proof. `--canonical` is still accepted as the explicit spelling of the default; selecting both flags fails.
- **Canonical compile still builds PSRD in memory.** `pipeline::build_canonical` calls `build_psrd` for carry-over, the curated book tree, and legal notices. The `--psrd` build is a separate package of that same legacy library, not a second data path.
- **CI proves both builds.** The content job compiles the canonical default twice from scratch and compares every generated byte, then compiles `--psrd` twice and compares `generated/psrd/` plus its reports. It also runs `check-library-upgrade.py generated/psrd generated/content`, so the default library must resolve every previous PSRD id. Publication and browser acceptance jobs use the canonical default.
- **No format change.** `SCHEMA_VERSION` stays 3 and `INDEX_FORMAT_VERSION` stays 1. The default selects a library; it does not change the serialized contract.
- **Facet lists are derived when the index is decoded.** `SearchIndex` stores document ordinals per kind, publication, and facet value. `filter_counts_eligible` evaluates each document against the active filter groups once and uses a failure mask to answer every chip, including the chip that ignores its own group. Search caches facet values and the discovery snapshot per selection revision, so typing and filter toggles stop rescanning the full index. Nothing is added to `search.bin`; the lists are rebuilt from metadata that format 1 already carries, so the serialized contract and every published index stay valid.
- **Release order follows design section 6.5.** An old shell reading a canonical library cannot resolve old bookmarks, while the new shell reads an old library safely. The alias-capable shell must therefore be published and verified on the PSRD release first, and only then may the owner promote the commit that makes canonical the default. Merging this change publishes nothing.
