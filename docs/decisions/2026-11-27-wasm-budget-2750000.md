# The WASM budget is 2,750,000 bytes until the filter refactor lands, 2026-11-27

PR #753 (precompressed library, slice 2: a Rust gzip fallback with miniz_oxide) measures 2,719,867 of
2,720,000 bytes, 133 bytes left. The next planned features (#754, an optional `feature` key on option
groups; slice 3 of #746) cannot fit, so `wasm_bytes` in `sources/size-budget.toml` rises to 2,750,000.

#744 (share the list filter code of the archetype and option lists) measures the binary with twiggy and
shrinks it, but it is a refactor and must not block those features. It does not lower this line by
itself; a later pull request may lower it to the measured size plus about 5%, as the earlier budget
decisions do.
