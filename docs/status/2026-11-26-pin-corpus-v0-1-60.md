# Corpus pinned to v0.1.60, 2026-11-26

`sources/corpus.toml` now pins `phynics/cast-iron-data` tag `v0.1.60`, commit
`60fe4ff54ca170c338256668c40a6cee25ba7fbe`. The tree hash is
`dffc95b4f32a7fca90fa493ecbf60d3f1e8a2d159454cccf482c91fc222dcc16`. It was computed with
`cargo xtask corpus-tree-hash` on the extracted codeload archive, and `cargo xtask fetch-sources` verified it.

Between v0.1.59 and v0.1.60, 305 entry files changed. None was added, deleted or moved, and no id changed. The
library still has 31,766 entries and 445 books. The data CI on the tag was green, with the checker built from app
`main`. All four data PRs in the range are part of [#540](https://github.com/phynics/cast-iron/issues/540),
under owner rulings 51 to 54 on that issue:

- **phynics/cast-iron-data#341** (cross-batch) gives level 1 to 162 features in 158 earlier entries, because each
  alters or replaces a whole 1st-level class feature (rulings 35, 48 and 50). It also restores the printed level
  of 17 more features. Only `features` lists change.
- **phynics/cast-iron-data#342** converts the archetypes of five books to printed prose: Potions and Poisons,
  Construct Handbook, Magic Tactics Toolbox, Haunted Heroes Handbook and Heroes from the Fringe (52 archetypes).
- **phynics/cast-iron-data#343** does the same for four books: Heroes of the Darklands, Legacy of Dragons, Familiar
  Folio and Advanced Class Origins (48 archetypes).
- **phynics/cast-iron-data#344** does the same for five books: Psychic Anthology, Disciple's Doctrine, Occult
  Origins, Arcane Anthology and Blood of the Coven (47 archetypes).
