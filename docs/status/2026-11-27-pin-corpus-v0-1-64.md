# Corpus pinned to v0.1.64, 2026-11-27

`sources/corpus.toml` now pins `phynics/cast-iron-data` tag `v0.1.64`, commit
`be094a3c87e85d61779ed010693c2cf3b2003908`. The tree hash is
`6322c087e3ffb8b87754707e803e2eec69908725babeff9960625007857c6938` (computed with
`cargo xtask corpus-tree-hash` on the extracted codeload archive; `cargo xtask fetch-sources` verified it).

**Class options are converted for the Advanced Player's Guide and Ultimate Magic** ([#540](https://github.com/phynics/cast-iron/issues/540)):
169 class options print as prose with `ability_type`, and the first class options with several powers carry
`features`. This is also the first pin whose `option-groups.toml` has `feature` keys
([#754](https://github.com/phynics/cast-iron/issues/754)).

Between v0.1.63 and v0.1.64, 187 entry files changed. None was added, deleted or moved, and no id changed; no
alias, exclusion or exception changed. The library still has 31,766 entries and 445 books. The data CI on the
tag commit was green. Data PRs in the range:

- **Class options, Advanced Player's Guide, part 2:** phynics/cast-iron-data#368 changes 77 entries. It includes
  the three cavalier orders with several powers (order of the cockatrice, order of the star and order of the
  sword), which carry `features`.
- **Class options, Ultimate Magic:** #374 converts the single-power options (92 entries).
- **Guards and fences:** #370 (a completeness guard for class options) and #371 (class-option fences) change no
  entry.
- **Rule entries:** #372 changes 18 entries. 16 Horror Adventures corruptions take print's labels (no `Flavor:`;
  "Corruption Stage N:" and "Prerequisite(s):"), `ref/ability/companion-tricks` loses its `Action: Trick` row,
  and `ref/rule/high-rp-types` changes page 217 to 215.
- **Option groups:** #376 adds `feature` keys: `inquisition` to `domain`, `summoner-evolution` and
  `unchained-summoner-evolution` to `eidolon`, and `witch-patron` to `patron-spells`.

The 169 converted class options are in these groups: `ref/arcana/` 20, `ref/arcanedisc/` 10, `ref/discovery/`
56, `ref/evolution/` 18, `ref/hex/` 21, `ref/oraclecurse/` 3 (haunted, tongues, wasting), `ref/order/` 3,
`ref/ragepower/` 1 (witch-hunter) and `ref/talent/` 37.

## Specs that this pin changes

None. Of the 187 changed entries, no spec names an id or a title of one as a literal: the specs that read class
options take them from the compiled corpus (`loadCorpus`, `corpusEntry`), and the power-layout tests of
`class-option-powers.spec.ts` use fixed import-form bodies for Evil Eye, Flight and Auspicious Mark, which this
pin does not touch. `entry-ability-type.spec.ts` still finds a class option without an ability type for its
control.

A new test in `class-options-section.spec.ts` covers the `feature` keys of #754: on the Inquisitor, Witch and
Summoner pages the row of Inquisitions, Witch patrons and Summoner evolutions sits under the Domain, Patron
Spells and Eidolon heading, after the text under the heading and before the next heading of the same or a
higher level.
