# Corpus pinned to v0.1.56, 2026-11-25

`sources/corpus.toml` now pins `phynics/cast-iron-data` tag `v0.1.56`, commit
`79cbe278c580392cb6c80f979232e646364067de`. The tree hash is
`7debe09fb671d4f93719478216c9e0f03cbc9e59b73f748988261914a2d0e78d` (computed with
`cargo xtask corpus-tree-hash` on the extracted codeload archive; `cargo xtask fetch-sources` verified it).
The previous pin was v0.1.54. This pin skips v0.1.55, whose changes v0.1.56 contains.

Between v0.1.54 and v0.1.56, 2,194 entry files changed and one was deleted: `entries/eq-weapon/combat-scabbard.md`.
Its id `ref/eq-weapon/combat-scabbard` is now an alias of `ref/eq-misc/combat-scabbard` (data #326,
phynics/cast-iron-data#267: print has one Combat Scabbard), so the published-id guard still resolves it. No other
entry file was added, moved or renamed and no id changed (the data PRs also add review tables under `scripts/`). The library has 31,671 entries (one fewer) and 443 books.
The data CI on the tag was green, with the checker built from app `main`. Six data PRs merged in the range:

- **#322** (phynics/cast-iron-data#282) corrects spell fields to print. Major Image is level 3 with the duration
  `concentration+ 3 rounds`, and Secret Vault has 60 days. Durations and components are fixed in 7 spells and
  class levels in 13. By the owner rulings of 2026-11-25, a class level is held only when print states it or a
  printed rule derives it (hunter, skald, warpriest, oracle).
- **#323** (phynics/cast-iron-data#284) adds 106 class levels and removes 9 unprinted ones.
- **#331** (phynics/cast-iron-data#287) writes the typed fields in one spelling each:
  - `creature_type` reads `magical beast` and `monstrous humanoid` (428 entries); the app accepts this since
    [#724](https://github.com/phynics/cast-iron/pull/724);
  - `size` is lower case (325);
  - alignments are written out (309);
  - `hit_die` loses its trailing period (120);
  - spell `subschools` are lower case (1,074 values);
  - `glamer` leaves `descriptors` (82);
  - bracketed descriptor lists move from `school` to `descriptors` (14 entries).
- **#324** ([#540](https://github.com/phynics/cast-iron/issues/540), batch 4) states every archetype of Ultimate
  Wilderness (126) and the Adventurer's Guide (38) as printed prose. Raven Master is among them, read with the
  reader of [#723](https://github.com/phynics/cast-iron/pull/723). The PR also adds or fixes 7 stored trades in
  earlier books (Alchemical Sapper, Tyrant, Hussar, Roof Runner, Savage Warrior, Rot Warden and others).
- **#326** makes Combat Scabbard one entry (above).
- **#330** (phynics/cast-iron-data#193) fixes one heading level.

## A spec that this pin changes

`tests/e2e/tests/feature-heads.spec.ts` used Lore Warden as its control: an archetype still in import form, with no
`features`. #324 converts Lore Warden, so the control would have shown feature heads. The spec now picks its
control from the compiled library: the first archetype, by id, that still has no `features`. When #540 has
converted every archetype, the control step has nothing to compare and returns. The test itself stays.
