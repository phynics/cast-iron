# Corpus pinned to v0.1.57, 2026-11-26

`sources/corpus.toml` now pins `phynics/cast-iron-data` tag `v0.1.57`, commit
`38c4d4ba735bdf636fec3e343476ee8d3c7fb2ef`. The tree hash is
`5f812f140dd5a9f0202415a9a5de41716ce6be12a93735b4eb055f7a8da01439` (computed with
`cargo xtask corpus-tree-hash` on the extracted codeload archive; `cargo xtask fetch-sources` verified it).

Between v0.1.56 and v0.1.57, 95 entry files were added and 116 changed. None was deleted or moved, and no
existing id changed. The library has 31,766 entries (95 more), 445 publications and 445 books. The data CI on the
tag was green, with the checker built from app `main`. Two data PRs merged in the range:

    detailed in each relevant class feature").
- **#325** (phynics/cast-iron-data#285) adds two publications, Guide to Pathfinder Society Organized Play 4.3 and
  the Pathfinder Society Roleplaying Guild Guide 8.0. Their share slots came first, in
  [#730](https://github.com/phynics/cast-iron/pull/730). It also adds 95 entries: 91 traits (the faction traits

## The printed-trade check is an error

This pin sets `PRINTED_TRADES_ARE_ERRORS` to true (`crates/corpus/src/check_printed_trades.rs`, from
[#728](https://github.com/phynics/cast-iron/pull/728)). v0.1.57 is the first tag with no printed trade sentence
that lacks a stored trade: `corpus-check` reports none, and the one exception row matches. The change also takes
the review notes of #728:
- `sentence_uncovered` in `drift.rs` is private again;
- the cross-reference test also asserts that a cross-referenced phrase asks for no trade when none is stored;
- the anaphoric test covers a bare "replaces it".
