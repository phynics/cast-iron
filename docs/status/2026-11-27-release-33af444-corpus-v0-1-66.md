- **Ten Core Rulebook classes show their class features as sections:** Barbarian, Bard, Cleric, Druid, Fighter,
  Paladin, Ranger, Rogue, Sorcerer and Wizard. 257 more class options are converted.

  fetched again.
- **Upgrading:** reload when Settings offers the app update, choose "Check now" again, then choose "Download update" (about 42.5 MB). Stars and
  book choices stay, and the current library keeps working until the new one is verified.
