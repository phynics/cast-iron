# Corpus pinned to v0.1.63, 2026-11-27

`6a5d55841ba2e7d0e3a7dffe0281f29ac84e6c34`. The tree hash is
`871b0d7dc3a1412046bf1504aec6198a00451676daddfb5b77ce296c5a3da47d` (computed with

## A spec that this pin changes

`tests/e2e/tests/class-option-powers.spec.ts` read Evil Eye and Flight as one-power class options in import
form. The class-option pilot converts both to printed prose with `ability_type`, so the import-form power
layout no longer applies to them. The spec now checks that layout on fixed import-form bodies (an overlay),
so it no longer depends on which class options the corpus has converted. It also checks the converted
Evil Eye.
