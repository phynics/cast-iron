# Decisions

Decisions are one file each in [`docs/decisions/`](decisions/README.md). The
[index](decisions/README.md) is generated by `cargo xtask decisions-index`. It lists every decision
by area, with its date, status and issues, and links an entry that a later decision replaced to the
entry that replaced it.

To record a decision, add `docs/decisions/YYYY-MM-DD-<slug>.md` with the front matter that the index
describes, then run `cargo xtask decisions-index`. Do not edit another entry's text. When a decision
replaces an earlier one, set the earlier entry's `status` and `superseded_by` and leave its text alone.

This page stays so that older links and references (`docs/decisions.md, "Title"`) find the right
place. Look the title up in the index.
